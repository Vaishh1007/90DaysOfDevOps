# Task 3: Explore Docker Terminologies and Components

## Key Docker Terms

1. **Docker Image** – A template that contains the application and all its dependencies. Think of it as a **blueprint** for creating containers.
2. **Docker Container** – A running instance of a Docker image. Containers are lightweight and isolated from each other.
3. **Dockerfile** – A script with instructions to build a Docker image. It tells Docker what to install and configure.
4. **Docker Volume** – A way to store data permanently, even if a container stops or gets deleted.
5. **Docker Network** – Allows multiple containers to communicate with each other securely.

## Main Docker Components

1. **Docker Engine** – The core software that runs and manages containers.
2. **Docker Hub** – A public library where you can find and share Docker images.
3. **Docker CLI** – A command-line tool that lets you run Docker commands.
4. **Docker Compose** – A tool to define and run multi-container applications using a single YAML file.
5. **Docker Daemon** – A background service that manages Docker containers and images.

## How These Components Work Together
- You **write a Dockerfile** to define your app’s setup.
- You **build an image** from the Dockerfile.
- You **run a container** from the image.
- You **use volumes** to store data permanently.
- You **use networks** to connect multiple containers.
- You **push and pull images** from Docker Hub to share or reuse them.

By understanding these key concepts, you can start using Docker effectively for your projects! 🚀
